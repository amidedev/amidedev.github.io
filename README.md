# amide.dev

Source for [amide.dev](https://amide.dev), the AMIDE marketing site. Deployed to GitHub Pages via `.github/workflows/deploy-pages.yml` on every push to `main`.

For the AMIDE coding agent itself, see [amidedev/amide](https://github.com/amidedev/amide).

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
